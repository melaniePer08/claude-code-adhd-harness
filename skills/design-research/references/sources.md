# Design research sources

The catalogue behind the `design-research` skill. Match the source to the problem —
see SKILL.md for which to reach for first.

---

## Whole-site inspiration

Complete website ideas, page structure, visual hierarchy, interaction, art direction.

| Source | URL | Use for |
|---|---|---|
| **Godly** | https://godly.design/ | Highly polished sites, creative layouts, unusual navigation, modern landing pages, experimental interaction, premium direction |
| **Awwwards** | https://www.awwwards.com/ | High-end web design, creative sites, interaction ideas, typography, visual storytelling, animation |
| **Land-book** | https://land-book.com/ | Landing pages, SaaS sites, product sites, portfolios, page structure, hero sections |
| **SiteInspire** | https://www.siteinspire.com/ | Clean layouts, typography, portfolios, editorial design, navigation, minimal interfaces |
| **Lapa Ninja** | https://www.lapa.ninja/ | Landing pages, marketing sites, hero sections, pricing, feature sections, CTA design |
| **One Page Love** | https://onepagelove.com/ | One-page sites, portfolios, landing pages, creative layouts, simple but polished structure |
| **Mobbin** | https://mobbin.com/ | **Real product UI** — app interfaces, dashboards, onboarding, settings, navigation, mobile, user flows, real-world UX patterns |
| **Dribbble** | https://dribbble.com/ | UI ideas, dashboards, cards, illustration, icons, visual concepts, interaction ideas |
| **Behance** | https://www.behance.net/ | Complete design systems, branding, portfolios, editorial design, art direction, typography, visual identity |

**Mobbin** is the one to reach for when designing an *application* rather than an
artistic website — it shows how real products actually solve a screen.

**Dribbble** is inspiration, not production-ready code. Plenty of it would not survive
contact with real content.

## Component sources

For an actual reusable implementation.

| Source | URL | Use for |
|---|---|---|
| **shadcn/ui** | https://ui.shadcn.com/ | **Preferred foundation.** Buttons, dialogs, dropdowns, forms, navigation, cards, tables, tabs, inputs, menus, command interfaces, general app UI. You own and modify the component code — that philosophy is the point. |
| **Magic UI** | https://magicui.design/ | Animated components, hero sections, animated text, bento layouts, visual backgrounds, hover effects. **Selectively** — do not fill a site with these. |
| **React Bits** | https://reactbits.dev/ | Creative React components, animation, text effects, backgrounds, interactive details. Good for one small element that makes a page feel distinctive. |
| **Motion Primitives** | https://motion-primitives.com/ | Micro-interactions, transitions, animated UI, text animation, page transitions. Subtle and purposeful. |
| **Origin UI** | https://originui.com/ | Forms, application UI, dashboards, inputs, menus, settings, practical patterns |
| **21st.dev** | https://21st.dev/ | Community components, modern React, experimentation. **Read the code before integrating** — do not trust every community component. |
| **HeroUI** | https://www.heroui.com/ | Modern application UI, accessible components, buttons, inputs, modals, navigation, cards, menus |
| **Componentry** | https://componentry.dev/ | UI components, modern interface patterns, polished elements |
| **Cult UI** | https://cult-ui.com/ | Distinctive UI, creative components, interesting interaction, visual personality. For when a project needs more character than standard SaaS UI. |
| **Aceternity UI** | https://ui.aceternity.com/ | Modern landing pages, animated backgrounds, hero sections, cards, hover and text effects, visually impressive sections. **Selectively** — not every page is a showcase. |

## Colour

| Source | URL | Use for |
|---|---|---|
| **Coolors** | https://coolors.co/ | Palettes, exploration, complementary colours, visual identity |
| **Realtime Colors** | https://www.realtimecolors.com/ | Testing a whole colour system, checking text/background combinations, previewing themes, accessibility-conscious choices |

Realtime Colors is the practical one: it shows a palette on a real layout rather than
as swatches, which is where most palettes fall apart.
